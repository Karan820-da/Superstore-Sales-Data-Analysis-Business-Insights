# Superstore Sales Data Analysis and Business Insights

## Project Overview

This project focuses on analyzing retail sales data to generate meaningful business insights. The analysis was carried out using Python, SQL, and Power BI to evaluate sales performance, customer behavior, and product trends.

---

## Tools and Technologies

* Python (Pandas, NumPy)
* SQL (MySQL)
* Power BI
* Jupyter Notebook

---

## Key Tasks Performed

* Cleaned and preprocessed the dataset by handling missing values and correcting data types
* Conducted exploratory data analysis (EDA) to identify trends and patterns
* Analyzed sales performance, profitability, and customer segments
* Developed an interactive dashboard to visualize key metrics

---

## Key Insights

* Identified top-performing products and categories contributing to overall revenue
* Analyzed regional sales distribution and performance trends
* Observed customer purchasing patterns and high-value segments
* Highlighted factors influencing profitability

---
